This repository holds the documentation used directly in the AI Maxxing Discord server — community guides, staff procedures, and moderation resources, maintained as plain Markdown.

## Quick start

```bash
git clone https://github.com/Rethunk-AI/discord-docs.git
```

See [HUMANS.md](HUMANS.md) for the full contributor workflow and prerequisites.

## Highlights

- Server rules live in [`info/rules.md`](info/rules.md)
- Staff user-case conventions live in [`staff/user-cases_post-guidelines.md`](staff/user-cases_post-guidelines.md)
- Pure Markdown — no build or runtime, verified with `make check`
- CC0 public domain — freely reusable
